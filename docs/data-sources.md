# データソース

世帯・家族類型の探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-04。軸は e-Stat API のメタ取得で確認済み。

## 1. 結論

一般世帯の家族類型を、**時代・世帯主年齢・地域**の3ビューで見せる。単位は人口ではなく**世帯数とその構成比**。UI・配信の共通類型は社人研の **5類型**（単独 / 夫婦のみ / 夫婦と子 / ひとり親と子 / その他）。国勢調査の16区分はビルド時に畳む。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代（実績） | 国勢調査 時系列「世帯」 | `0003414255` | 類型×全国×調査年 | 世帯数・構成比・平均人員 |
| 時代（推計） | 社人研 R6(2024)年推計 | Excel 結果表1 / 概要表2 | 5類型×年（〜2050） | 世帯数・構成比・平均人員 |
| 世帯主（実績） | 同上 時系列 | `0003414256` | 類型×世帯主年齢×男女×年 | 世帯数・構成比 |
| 世帯主（推計） | 社人研 結果表2 | Excel | 5類型×年齢×男女×年 | 世帯数・構成比 |
| 地域 | `0003414255` | 類型×都道府県×年 | 世帯数・構成比・相対指標（全国比） |
| 高齢単独（補強） | `0003410427` | 性×年×地域（65歳以上単独） | 世帯数 |

出典表記: 総務省「国勢調査」（e-Stat）、国立社会保障・人口問題研究所「日本の世帯数の将来推計（全国推計）令和6(2024)年推計」。

## 2. 採用データセット（メタ実測）

### `0003414255` — 国勢調査 時系列（時代・地域の実績）

- 統計名: 時系列データ 世帯
- 表題: 世帯の家族類型（16区分）別一般世帯数及び世帯人員－全国，都道府県（平成7年～令和2年）※新分類区分
- 軸: 表章項目(4) × 家族類型16区分(20) × 地域(48: 全国+47県) × 調査年(6: 1995–2020)
- 公称件数 23,040 / 軸の積と一致
- 表章: `6` 一般世帯数 / `7` 一般世帯人員 / `1390` １世帯当たり人員 / `1930` 世帯数割合
- **性別軸なし**（地域・時代の実績は総数のみ）
- 調査年に不詳補完値の別コードは無い（各年1本）

### `0003414256` — 国勢調査 時系列（世帯主ビュー実績）

- 表題: 世帯の家族類型（16区分），世帯主の年齢（5歳階級），世帯主の男女別一般世帯数及び一般世帯人員－全国（平成7年～令和2年）※新分類区分
- 軸: 表章(2) × 類型(20) × 年齢(17) × 男女(3) × 年(6)
- 公称件数 12,239（疎）
- 性別: `100` 総数 / `110` 男 / `120` 女
- 年齢配信対象: `15～19` … `80～84` / `85歳以上`（総数・15歳未満は除外）

### `0003410427` — 65歳以上単独世帯（補強）

- 表題: 年齢（5歳階級），男女別65歳以上の単独世帯数－全国，都道府県（昭和55年～令和2年）
- 1980–2020。時代ビューで単独を選んだときの再掲系列・注記に使う。

### 社人研 Excel（`data/raw/ipss/`）

取得元: https://www.ipss.go.jp/pp-ajsetai/j/HPRJ2024/t-page.asp

| ファイル | 用途 |
| --- | --- |
| `gaiyo_hyo.xlsx` 表2 | 1980–2050 の5類型世帯数・割合（接続確認・長期注記） |
| `kekka1.xlsx` 結果表1 | 2020–2050 年次の類型別世帯数・人員・平均人員（単位: 千世帯） |
| `kekka2.xlsx` 結果表2 | 世帯主年齢×類型×男女（推計年シート。単位: 千世帯） |

**単位注意**: 社人研 Excel の世帯数は **1,000世帯**。配信では国勢調査と同じ「世帯」に揃えるため ×1000 する。

## 3. 16区分 → 5類型の畳み方

葉カテゴリのみ合算（中間集計行は使わない）。

| 5類型コード | 表示名 | 国勢コード |
| --- | --- | --- |
| `alone` | 単独 | `290` |
| `couple` | 夫婦のみ | `130` |
| `couple_child` | 夫婦と子 | `140` |
| `single_parent` | ひとり親と子 | `150` + `160` |
| `other` | その他 | `180`–`270` + `280` |
| `total` | 総数 | `100` |

## 4. 接続ルール

- **2020年**は国勢調査実績を優先。推計の基準年と重なるが配信では実績。
- **2025年以降**を推計とし、チャート上は破線・帯ラベル「推計」で区別。
- 地域ビューに推計は載せない（全国推計に都道府県軸がない。都道府県別将来推計は第1版スコープ外）。
- 世帯主ビューは全国のみ。結果表2があれば 2025–2050 も載せる。
- 時代の性別: 実績・推計とも**総数のみ**（表に性別が無い）。世帯主ビューで男女を見る。

## 5. 配信ファイル

`scripts/build.ts` が `public/data/` に書く。

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | type × year | households, share, meanSize, projected | types |
| `head-age.json` | type × age × sex × year | households, share, projected | types, ages |
| `geo.json` | type × year × area | households, share, relative | types, areas |
| `elderly-alone.json` | sex × year | households | — |

cube 形式は `dims` + `measures`（行優先フラット配列）+ 辞書配列。欠測は `null`。
`share` / `relative` は小数4桁。`projected` は 0=実績 / 1=推計。

相対指標:

\[
\mathrm{relative} = \frac{\text{県の当該類型構成比}}{\text{全国の当該類型構成比}}
\]

## 6. 注記（UIに短く出す）

- 家族類型は平成7年以降の新分類で接続（1995–2020）。
- 2025年以降は社人研の将来推計（世帯主率法）。仮定の詳細は報告書を参照。
- 単位は世帯。人口ピラミッドとの横断比較を主眼にしない。

## 7. 更新手順

```
npm run meta
npm run fetch
npm run data
npm run verify
```

`ESTAT_APP_ID` は `.env` に置く（コミットしない）。社人研 xlsx は上記 URL から `data/raw/ipss/` へ取得（gitignore）。配信用 JSON は追跡する。
